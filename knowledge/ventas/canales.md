# Canales de venta ficticios

Documento ficticio sobre ventas de Telecom Demo Knowledge.

## Canales

La empresa vende mediante tiendas propias, distribuidores autorizados, venta telefónica, sitio web y aplicación móvil. Cada canal tiene comportamiento distinto. Las tiendas propias atienden altas pospago y consultas complejas. Los distribuidores se enfocan en prepago. El sitio web y la aplicación móvil concentran ventas digitales.

## Datos sintéticos

En un mes ficticio, el cuarenta por ciento de las altas prepago provino de distribuidores, el veinte por ciento de la aplicación móvil y el quince por ciento del sitio web. En pospago, las tiendas propias tuvieron mayor participación. Estos porcentajes son inventados y no representan una empresa real.

## Relación con churn

El canal de venta puede influir en la experiencia inicial. Si la explicación del plan fue incompleta, el cliente puede tener dudas sobre facturación o beneficios. Una venta digital puede requerir mensajes educativos posteriores. Una venta telefónica puede requerir validación adicional de consentimiento.

## Uso educativo

Este documento permite probar preguntas sobre canales, ventas digitales, tiendas, distribuidores y relación entre experiencia comercial y abandono temprano.
