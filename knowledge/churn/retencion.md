# Retención ficticia

Este documento contiene estrategias inventadas para reducir abandono temprano en Telecom Demo Knowledge.

## Objetivo

La retención busca actuar antes de que el cliente abandone. El equipo ficticio prioriza casos donde hay señales tempranas de frustración, poca actividad o problemas de instalación. La meta educativa es observar cómo diferentes documentos pueden complementar una respuesta RAG.

## Acciones para prepago

Para clientes prepago con riesgo, se puede enviar un bono de bienvenida, una guía simple para comprar paquetes y un recordatorio de beneficios. Si el cliente no realizó recargas durante los primeros veinte días, el caso puede recibir una campaña automática. Si tampoco hay consumo de datos, se marca para seguimiento adicional.

## Acciones para pospago

Para clientes pospago, la retención ficticia usa llamadas de bienvenida, explicación de factura proporcional y seguimiento después del primer reclamo técnico. Si existen dos reclamos durante el primer mes, el caso pasa a atención prioritaria. Si el cliente expresa intención de baja, se registra una causa tentativa como precio, cobertura, facturación o experiencia de venta.

## Acciones para hogar

Para clientes hogar, la prioridad es completar la instalación y validar calidad durante los primeros días. Si una visita técnica se reprograma varias veces, el sistema genera alerta. Si el cliente reporta baja velocidad inicial, se agenda revisión preventiva. Estas reglas son ficticias y sirven para estudiar recuperación semántica.
